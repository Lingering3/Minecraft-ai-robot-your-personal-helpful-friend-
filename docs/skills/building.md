# 建筑 Skill

> 状态：设计契约。适用于 StepFun 已确认 `build`，即玩家要求实际搭建成品。

## 目的

StepFun 根据玩家完整表述与 `BlueprintCatalog` 当前返回的候选，决定 `build_kind` 和一个**真实存在**的蓝图 ID。StepFun 不负责判断 `build_kind`。谈论、询问或评价建筑属于聊天；索要图纸物品属于指令，不进入此 Skill。

## 输入

- 原始对话消息，包括风格、用途、尺寸和建筑名称。
- 当前蓝图库中每个候选的原始 ID、中文显示名、标签与尺寸。
- 玩家模式、当前位置及是否要求蓝图确认。

## 输出与约束

```text
建筑类型: <build_kind>
最终选择: <蓝图库中的原始 ID>
```

ID 可能包含空格，必须保持原样。程序核对 ID 并加载蓝图；找不到或加载失败时明确报告，不能编造蓝图，也不能无提示地换成默认建筑。默认流程把蓝图物品给玩家，由玩家预览、旋转并确认位置，然后进入建造任务。运行时进度应使用蓝图的中文显示名。
