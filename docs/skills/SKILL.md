## 输入与路由

输入为玩家原话、Laya 返回的主意图，以及机器人和玩家的必要上下文。按 **主意图** 选择对应文档；不要仅凭句中出现“建筑”“命令”等词重分类。

| Laya 主意图 | 领域文档 | 处理目标 |
|---|---|---|
| `chat` | 无 | 自然回答；不调用会改变世界的动作 |
| `build` | [建筑 Skill](building.md) | 选择建筑类型与实际可用蓝图 |
| `command` | [指令 Skill](command.md) | 选择受支持的游戏管理指令及参数 |
| `follow` / 移动相关 | [运动 Skill](movement.md) | 选择跟随、移动或待命动作 |
| `mine` / `gather` / 其他任务 | 对应任务工具与 Goal/Task 规则 | 使用已注册的工具和确定性任务 |

## 通用约束

1. Laya 只确定领域，不直接指定蓝图 ID 或执行游戏指令。
2. StepFun 只在已确定的领域内选择行动；候选来自当前注册工具、蓝图库或白名单。
3. 所有模型输出由程序检查。未知 ID、非法参数、缺失目标或执行失败都必须明确反馈。
4. “聊到建筑”不等于“请求建造”；“命令式语气”不等于 `command`。
5. 当前工程没有本地猜测式蓝图兜底；无法从候选中选出目标时报告失败。
