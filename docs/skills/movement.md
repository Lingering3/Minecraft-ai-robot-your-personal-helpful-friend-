# 运动 Skill

> 状态：设计契约。适用于 StepFun 判定为 `follow` 或其他明确移动请求后。

## 目的

让 StepFun 根据玩家原话与可见世界状态，在**已注册的移动/跟随任务**中选择合适动作。询问“你能过来吗”可能只是聊天；只有明确要求机器人移动时才进入这里。

## 需要的上下文

- 玩家与机器人当前可见位置、维度、距离及任务状态。
- 玩家是要求“跟随我”“走到这里”“在原地等”，还是停止现有移动。
- 当前工具注册表中实际可用的动作及其参数。

## 决策与执行

持续跟随交给跟随任务；到指定位置交给移动任务；待命或停止按已有任务控制语义处理。StepFun 不应凭空发明坐标或工具名。服务器端寻路和动作代码负责逐步移动与碰撞处理，模型不生成每个游戏 tick 的位置。目标不可见、跨维度或路径失败时，向玩家说明实际原因。
